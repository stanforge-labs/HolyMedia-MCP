Вы контролируете действия

Изменения — только после подтверждения

По умолчанию HolyPilot читает данные. Если доступно изменение, сервис сначала показывает его предварительный результат и ждёт вашего отдельного подтверждения.

  • Данные вашей компанииДоступ ограничен её участниками и подключёнными кабинетами.
  • Официальное подключениеПароли рекламных платформ не передаются HolyPilot.
  • Ручное решениеБез подтверждения доступное изменение не применяется.
