# Opportunities / Возможности оптимизации

Use READ results before proposing any action. Depending on the connected provider and listed tools, examine `get_top_performers`, `get_campaign_statuses`, `google_ads_search_terms`, `google_ads_list_keywords`, `google_ads_list_negatives`, and `google_ads_check_negative_conflicts`. Scope every call to the user-authorized workspace and account. Explain why an observation matters and what additional evidence would confirm it.

Present each suggestion as a hypothesis with supporting data, expected effect, uncertainty, and a reversible next step where applicable. A search term is not automatically a negative keyword; check existing keywords and negative conflicts. Do not claim provider-wide coverage from a limited response. This skill only recommends. It never calls preview or commit without a separate user request.

Русский формат: сигнал → доказательство → гипотеза → возможное действие → риск и проверка. Не считай тестовую или историческую приёмку доказательством текущего состояния кабинета.
