# HolyPilot OpenAI Plugin 0.1.1 — evidence matrix

**B2.1 release gate status:** The code-only release path prevents the PR #10 migration merge from entering the ordinary Web/API/Worker deploy matrix. A separate workflow depends on preflight, then API, then a public OIDC gate, then Web; it has no Worker job. This is an offline workflow contract, **not production PASS**. Disposable Docker validated non-root read access, RS256 signing, public-only JWKS and fail-closed unreadable key. Production key mount, backup, migration, actual VPS preflight and native OpenAI Portal Validate remain BLOCKED. See `B2_1_VPS_PREFLIGHT_CHECKLIST.md` and `PRODUCTION_ROLLOUT_PLAN.md`.

The temporary source-controlled release hold blocks subsequent ordinary Web/API pushes until the approved one-time rollout passes; Worker-only changes remain deployable. Removal is a separate reviewed post-release commit.
