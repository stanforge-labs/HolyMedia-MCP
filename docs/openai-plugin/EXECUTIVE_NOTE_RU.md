# Для руководителя Holy Media

Подготовлено точечное обновление существующего OpenAI Plugin до черновой версии **HolyPilot 0.1.1**. Публичное название и официальный знак унифицированы; MCP остаётся по адресу `/mcp/public` и даёт доступ только к 41 инструменту чтения. Для корпоративных ограничений по домену email добавлен код OIDC с проверяемой подписью и осторожной классификацией подтверждённого адреса. Старые подключения `/mcp` сохраняются, Google Ads WRITE не включается.

Это **не релиз**: OIDC ещё не работает на production, нужны защищённые ключи и отдельное разрешение на аддитивную миграцию и штатный Web/API deploy. Также нужно проверить бизнес-верификацию OpenAI, юридические сроки хранения и право использования провайдерских API. Общая схема пакета Agent Plugins сейчас конфликтует с документацией OpenAI об обязательной OAuth-конфигурации; до нативной Validate в портале нельзя заявлять пакет полностью готовым к отправке.
