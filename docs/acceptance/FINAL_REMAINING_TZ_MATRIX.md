## Границы подсчёта

- **7/39** имеют прежний ограниченный LIVE PASS; **32/39** не приняты в полном объёме. Это не процент завершения, поскольку размер и условия групп различаются.
- **39/39** имеют хотя бы проверяемую кодовую границу; **38/39** имеют реализованный локально проверяемый профиль без известного отсутствующего компонента. Строка **0.04** остаётся исключением: внутренний success-only audit есть, но действительного Google `sign_up` measurement/delivery нет. Это число не означает, что все варианты 38 групп прошли provider или exhaustive API compatibility.
- PMax 4.06 содержит шесть разных LIVE-проверок: asset groups, текст/изображения, audience signals, search themes, negative keywords, brand exclusions. Все шесть сейчас **CODE ONLY / LIVE BLOCKED**; fixture является prerequisite, не седьмой исходной группой.
- G10 объединяет Q LIVE PASS, Claude R/M PARTIAL, S PARTIAL. Общая строка G10 остаётся PARTIAL.
- Изменение рекламных аккаунтов, backend TEST, VPS и production не входило в этот offline этап.

## Проверенные официальные API-границы

- [Google test accounts](https://developers.google.com/google-ads/api/docs/best-practices/test-accounts): не обслуживают объявления; impressions, conversions и cost пусты. Буквальные §§83–85 и фильтрация по CPA требуют настоящего разрешённого источника данных.
- [Conversion actions](https://developers.google.com/google-ads/api/docs/conversions/getting-started) и [WEBPAGE category](https://developers.google.com/google-ads/api/docs/conversions/categories): создание action — настройка; для измерения сайта нужен tag. Внутренний audit регистрации не является Google conversion.
- [PMax asset requirements](https://developers.google.com/google-ads/api/performance-max/asset-requirements), [atomic request structure](https://developers.google.com/google-ads/api/performance-max/structure-requests), [asset-group signals](https://developers.google.com/google-ads/api/performance-max/asset-group-signals), [campaign criteria](https://developers.google.com/google-ads/api/performance-max/create-campaign-criteria): минимальный набор ассетов, parent resources, ownership, signals, negative keywords и brand exclusions имеют отдельные условия. Отсутствие eligible audience/BRANDS в TEST — внешнее условие, не запрет Google API.
- [OAuth](https://developers.google.com/google-ads/api/docs/oauth/internals): scope `https://www.googleapis.com/auth/adwords`; [developer token](https://developers.google.com/google-ads/api/docs/oauth/overview) обязателен. [v24 sunset schedule](https://developers.google.com/google-ads/api/docs/sunset-dates) указывает май 2027 как плановую дату, поэтому при release потребуется проверить версию ещё раз.
