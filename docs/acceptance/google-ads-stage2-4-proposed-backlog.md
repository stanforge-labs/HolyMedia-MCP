## Tool, schema and account security integration

Stage0: `create_campaign_from_brief`, `get_launch_checklist`, `preview_resume_campaign`, `clone_campaign_preview`. Pending scoped fix adds strict Google branch to existing `preview_pause_campaign`, not a raw mutate tool. Stage1: `create_keyword_from_brief`, `pause_entities_preview`, `update_entity_status_preview`, `google_ads_change_keyword_match_type_preview`, `preview_update_object` (keyword final_url only), `preview_delete_or_archive_object` (keyword permanent removal only), `google_ads_negatives_preview`, `google_ads_create_shared_negative_list_preview`, `google_ads_shared_negative_members_preview`, `google_ads_shared_negative_campaigns_preview`, `google_ads_search_term_to_negative_preview`, `google_ads_search_term_to_keyword_preview`, `list_change_journal`, `preview_rollback_commit`, shared `commit_preview`.

Required integration invariants:

- Google schema recursively rejects unknown properties; explicit `provider=GOOGLE_ADS`, account ID and typed identities. No arbitrary REST endpoint, resource, field mask or replacement plan supplied by caller.
- `PROVIDER_GOOGLE_ADS_WRITE_ENABLED=false`; `GOOGLE_ADS_WRITE_ACCOUNT_ALLOWLIST=` empty denies every account. Keep defaults OFF. Effective isolated acceptance gates are separately inspected, not shipped as defaults.
- Real commit also requires `V2_PREVIEW_ONLY=false`, `V2_CONFIRMED_WRITE_ENABLED=true`, allowed active service key with read+write scopes, live membership/workspace/account/connection access, correct creator browser approval, unexpired exact preview. Independent checks at preview, browser context, commit and adapter must remain.
- `PUBLIC_MCP_WRITE_SCOPE_ENABLED=false` and `PUBLIC_MCP_CONTROLLED_WRITE_ENABLED=false` stay OFF. Public OAuth Google write is not the implemented delivery path; controlled Google uses legacy scoped service-key `/mcp`. Generic Google writes must not become Public just because names coincide with Meta Public tool names.
- `claimGooglePreview` CAS binds provider/account/connection/workspace/token/approved user+session/payload/before/requested/digest/unconsumed TTL and current token/revocation/account restrictions. `STATIC_ALLOWLIST=[]` never means all-connected.
- Google OAuth `adwords` and current MCC `login-customer-id` remain, selected resource must belong to target customer. Never expose tokens, approval nonces, credential values or raw HTTP headers in documents/logs.
- Meta compatibility schema/dispatch regression and existing Google READ regression are mandatory: common preview/registry changes affect both providers. No new DB schema/migration justified for these existing stages.
- No release or assertion based only on HTTP200: operation-level requested→actual reread must verify every effect. Preview validation can call Google but must not create delivery objects; record validation and real mutation calls separately.

## Journal and rollback limits

Shared durable state is `McpPreview.beforeState/requestedState/providerResult/verificationRead/commitAttemptedAt/commitStatus` + `AuditService`. Attempt audit precedes mutation; DB/audit failure before mutation must fail closed. Result persistence failure after mutation never makes token reusable. Stable opaque commit IDs allow account/workspace-bound paginated journal investigation; filters cannot grant access.

| Operation                    | Safe inverse support                                   | Constraint                                                                                        |
| ---------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| Keyword ENABLED/PAUSED       | New inverse preview from verified changed rows         | Server recorded before+unchanged post-state; failed/no-op excluded; new browser approval required |
| Keyword final URL            | New inverse preview restores full recorded array/empty | Only verified successful rows; partial-success batch allowed; failed/unverified excluded          |
| Keyword REMOVED              | None                                                   | Permanent; prefer PAUSE                                                                           |
| Match replacement            | None automatic                                         | Inspect both actual resources; new explicit status previews, not replay consumed commit           |
| Negative/shared list/create  | None automatic                                         | Journal is evidence, not authorization for automatic inverse                                      |
| Stage0 created campaign/tree | None delete rollback                                   | Keep PAUSED; never repeat uncertain atomic create                                                 |
| Campaign resume→PAUSE        | Pending scoped typed fix                               | New preview + independent approval + reread; not `preview_rollback_commit` support                |

No provider CAS exists in this implementation; stale reread reduces but cannot remove the race between last read and mutate. No transaction spans Google+Postgres. Response loss,5xx or reread outage = uncertain/unverified + consumed claim, reconciliation READ only, never automatic mutation retry. In an emergency use operator-approved delivery-stop path, not a generalized automatic rollback claim.
